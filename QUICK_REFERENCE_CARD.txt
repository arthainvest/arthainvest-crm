✨ COMMON TASKS IN 30 SECONDS

ADD A NEW LEAD:
  1. Click "All Leads" → Click "+ Add Lead"
  2. Name, Phone, Email, Status, Budget
  3. Click "Save Lead"

ADD A DOCUMENT:
  1. Click "Documents"
  2. Find client name
  3. Click "+ Add Document"
  4. Name, Type (PAN/Aadhaar/Insurance/etc)
  5. Click "Upload Document"

SHARE MARKETING MATERIAL:
  1. Click "Marketing" → Create material (if new)
  2. Click "📱 WhatsApp" or "✉️ Email"
  3. Select clients
  4. Click "Share"

ADD A NEW TEAM MEMBER:
  1. Click "Manage Users" → Click "+ Add User"
  2. Username, Password, Full Name, Role
  3. Click "Save User"

CHANGE MY PASSWORD:
  1. Click "Settings"
  2. (Future feature - Settings page)
  3. OR Ask admin to reset

EXPORT DATA:
  1. Click "All Leads"
  2. Click "Export" button
  3. Save CSV file

🐛 QUICK TROUBLESHOOTING

Can't Login
  → Check username (lowercase)
  → Check password (exact match)
  → Check CAPS LOCK is off
  → Ask admin to reset password

Can't See "Manage Users"
  → You're Employee, not Admin
  → Login as admin: artha/artha123
  → Then you'll see ADMIN section

Document Won't Upload
  → File size < 10MB
  → File format: PDF, PNG, JPG
  → Internet connection active
  → Try different document type

WhatsApp Not Working
  → Client has phone number saved
  → Phone format: +919876543210
  → WhatsApp installed/available
  → Try Email instead

Can't Save Lead
  → Lead name is required
  → Check all fields filled
  → Refresh page (F5)
  → Try again
