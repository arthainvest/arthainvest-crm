================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: "Python is not installed or not in PATH"
SOLUTION:
- Install Python from https://www.python.org/
- During installation, CHECK "Add Python to PATH"
- Restart Command Prompt and try again

ISSUE: "Module 'PyQt5' not found"
SOLUTION:
- The RUN_CRM.bat script should auto-install it
- If it doesn't work, manually run:
  pip install PyQt5 -q

ISSUE: Application doesn't start
SOLUTION:
- Try running RUN_CRM.bat again
- Check that Python is properly installed
- Look at the error message in the Command Prompt window
- Try: python arthainvest_crm_app.py (to see detailed errors)

ISSUE: Database is corrupted
SOLUTION:
- Delete arthainvest_crm.db file
- Re-run RUN_CRM.bat
- A fresh database will be created with demo data
