## Troubleshooting

### Data Not Showing?
1. Ensure files are in correct folders
2. Check file names match expectations
3. Verify Business/Dashboard/ArthaInvest folders exist
4. Restart the CRM application

### Commission Updates Not Visible?
1. Update Commission Tracker.xlsx
2. Restart Data Hub view
3. Check file is saved properly

### Missing Client Records?
1. Verify CAN RECORDS files are in ArthaInvest folder
2. Check file format is .xls or .xlsx
3. Ensure folder permissions are correct
