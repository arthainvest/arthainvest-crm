## 🔐 DigiLocker - Secure Client Data Storage

### **What is DigiLocker?**

Secure cloud-based storage for client documents with role-based access control.

**Features:**
✓ Encrypted document storage
✓ Role-based access (Admin vs. Employee)
✓ Automatic expiry tracking
✓ Document search & tagging
✓ Version history
✓ Audit trail logging
✓ Compliance-ready

### **Document Categories**

| Category | Usage | Expiry |
|----------|-------|--------|
| KYC | Know Your Customer verification | 1 year |
| Bank Statements | Financial proof | None |
| Insurance Policy | Policy documents | 1 year |
| Loan Agreement | Loan documents | None |
| Investment Proof | Investment verification | None |
| Income Certificate | Income proof | 1 year |
| PAN Card | Tax ID | 10 years |
| Aadhar Card | ID proof | 10 years |
| Address Proof | Address verification | 2 years |
| Other Documents | Any other docs | Custom |

### **How to Use DigiLocker**

**Upload Document:**
1. Click "DigiLocker" in left sidebar
2. Click "Upload Document"
3. Select document category
4. Choose file from computer
5. Add tags (optional)
6. Click "Upload"
7. Document saved securely

**Access Control:**

**For Admin:**
- See ALL employee documents
- Download any document
- Delete documents
- Share with clients
- Generate reports

**For Employees:**
- Upload their own documents
- Download their own documents
- Share documents with admin for approval
- View only their own documents
- Cannot see other employees' data

**Example:**
- Rajesh (Sales) uploads: His client KYCs

- Admin can see ALL documents

## 📄 Invoice Generation System

### **Features**

✓ Automated invoice creation
✓ GST calculation (18% rate - customizable when registered)
✓ Multiple payment methods
✓ Invoice tracking
✓ Payment status updates
✓ Email delivery
✓ PDF download
✓ Invoice duplication
✓ Admin approval

### **How to Create Invoice**

1. Click "Invoices" in left sidebar
2. Click "New Invoice"
3. Fill details:
   - Client Name
   - Service Type (Insurance, Loan, Mutual Fund, etc.)
   - Amount (₹)
   - Description
   - Payment Method
   - Due Date (auto-set to 14 days)
4. Review GST calculation
5. Click "Create Invoice"
6. Invoice gets unique ID (ARTH-1001, ARTH-1002, etc.)

### **Invoice Example**

```
ARTH-1001
Date: 2026-08-10

Client: Rajesh Kumar
Service: Insurance Policy Commission
Amount: ₹4,500.00
GST (18%): ₹810.00
─────────────────
Total: ₹5,310.00

Due Date: 2026-08-20
Status: Paid (2026-08-10)
```

### **Invoice Status Workflow**

```
Draft → Sent → Pending → Paid
```

**Status Descriptions:**
- **Draft:** Invoice created but not sent
- **Sent:** Invoice sent to client
- **Pending:** Awaiting payment
- **Paid:** Payment received

### **Payment Methods**

- Bank Transfer
- UPI
- Credit Card
- Debit Card
- Cheque
- Cash

### **Invoice Actions**

- **Send by Email:** Automatically sends invoice to client's email
- **Download as PDF:** Create PDF copy for records
- **Update Status:** Change payment status
- **Duplicate:** Copy invoice to create similar one
- **Delete:** Remove draft invoices

### **Analytics**

For each employee/admin:
- Total invoices generated
- Total amount invoiced
- Amount paid
- Amount pending
- Average invoice value
- Payment status breakdown

**Admin View:**
- All invoices across team
- Per-employee statistics
- Monthly/quarterly reports
- Revenue tracking

### **GST Registration**

## 🎤 Voice Assistant Mobile App

### **What is Voice Assistant?**

Mobile app feature allowing employees to update client status with one-click voice commands while on the field.

### **How It Works**

**Step 1:** Employee taps microphone button
**Step 2:** Speaks status update command
**Step 3:** AI recognizes command
**Step 4:** Status automatically updates in CRM
**Step 5:** Confirmation message shows

**Total Time: < 2 seconds**

### **Voice Commands**

| Command | Action | Status |
|---------|--------|--------|
| "Call completed" | ✓ Mark call done | Call Completed |
| "Proposal sent" | ✓ Send proposal | Proposal Sent |
| "Waiting for response" | ⏳ Pause | Awaiting Response |
| "Follow up scheduled" | 📅 Schedule follow-up | Follow-up Scheduled |
| "Deal closed" | ✅ Close deal | Deal Closed |
| "Client not interested" | ❌ Not interested | Not Interested |
| "Schedule meeting" | 🤝 Book meeting | Meeting Scheduled |
| "Document required" | 📋 Request docs | Documents Required |

### **Voice Assistant Features**

✓ Real-time speech recognition
✓ Works offline (with cached commands)
✓ Multiple language support (English, Hindi, etc.)
✓ High accuracy (85-98%)
✓ Instant feedback
✓ Fallback to quick buttons
✓ Activity logging
✓ No manual typing needed

### **Quick Status Buttons** (If Voice Fails)

8 quick-tap buttons for common status updates:
- 📞 Call Completed
- 📄 Proposal Sent
- ⏳ Awaiting Response
- 📅 Follow-up Scheduled

## 📞 Support & Help

**Common Issues:**

**Q: Employee can't login?**
A: Check username/password from Employee Login table. Passwords are case-sensitive.

**Q: Can't access marketing integrations?**
A: Need API keys from each service. Get them from Canva, OpenAI, etc.

**Q: Voice commands not working?**
A: Ensure microphone permissions granted. Use quick buttons as fallback.

**Q: Documents not visible in DigiLocker?**
A: Check your access level. Employees only see their own documents.

**Q: Invoice not calculating GST correctly?**
A: GST rate is 18% by default. Custom rates can be set by admin.
