## 🎯 WHAT IS THIS?

Documents feature lets you store client files organized by folder:
- One folder per client/lead
- Track document types (PAN, Aadhaar, Insurance, etc.)
- See who uploaded and when
- Delete old documents

- Auto-tracks uploader name

Document Organization:
- One folder per client
- All client documents in one place
- Easy to find

Document Management:
- View all documents
- Delete old documents (with confirmation)
- See metadata for each document

Role-Based Access:
