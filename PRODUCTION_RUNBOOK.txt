BACKUP OPERATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DAILY AUTOMATIC BACKUP (8:00 AM):
  Location: C:\Users\artha\LaptopHub\CRM_APP\backups\
  Status: Automated via Task Scheduler
  Retention: Last 7 days (automatic cleanup)

WEEKLY MANUAL BACKUP (Friday 5:00 PM):
  Command: powershell -File CRM_Dashboard.ps1 -Action Create-Backup
  Location: C:\Users\artha\LaptopHub\CRM_APP\backups\
  Action: Copy to External USB drive

MONTHLY ARCHIVE (Last day of month):
  Command: Create backup manually
  Location: Copy to Google Drive or OneDrive
  Retention: 12 months

LIST AVAILABLE BACKUPS:
  Command: powershell -File CRM_Dashboard.ps1 -Action List-Backups
  Output: Shows all backup points with dates and sizes

RESTORE FROM BACKUP:
  Command: powershell -File CRM_Dashboard.ps1 -Action Restore-Backup -BackupName "CRM_Backup_2026-08-13_112840"
  Warning: This overwrites current data! Backup current state first.

EXPORT DATA TO JSON:
  Command: powershell -File CRM_Dashboard.ps1 -Action Export-All
  Location: C:\Users\artha\LaptopHub\CRM_APP\exports\
  Files: Leads.json, Calls.json, Commissions.json, Targets.json, Manifest.json

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE: Backend server won't start
  Solution 1: Check if port 3001 is already in use
  Solution 2: Kill existing node process: taskkill /F /IM node.exe
  Solution 3: Restart computer and try again

ISSUE: "Database file not found" error
  Solution 1: Verify file exists: C:\Users\artha\LaptopHub\CRM_APP\arthainvest-10-10.db
  Solution 2: Check permissions on database file
  Solution 3: Restore from backup if file corrupted

ISSUE: Can't login to CRM
  Solution 1: Verify server is running (check console output)
  Solution 2: Refresh browser (Ctrl+F5)
  Solution 3: Clear browser cache and cookies
  Solution 4: Restart backend server

ISSUE: Backup failed
  Solution 1: Check disk space (need at least 100 MB free)
  Solution 2: Verify backup directory exists and is writable
  Solution 3: Check logs for detailed error message
  Solution 4: Try manual backup with PowerShell

ISSUE: Data looks wrong
  Solution 1: Check when data was last modified (check logs)
  Solution 2: Export data to review (powershell -File CRM_Dashboard.ps1 -Action Export-All)
  Solution 3: Restore from previous backup if needed
  Solution 4: Contact support

SCENARIO: Accidental data deletion
  Recovery Time: 5 minutes
  Action: Restore from daily backup
  Command: powershell -File CRM_Dashboard.ps1 -Action Restore-Backup

SCENARIO: System crash / Hard disk failure
  Recovery Time: 10 minutes
  Action: Restore yesterday's backup
  Command: powershell -File CRM_Dashboard.ps1 -Action Restore-Backup -BackupName "previous_date"

SCENARIO: Database corruption
  Recovery Time: 15 minutes
  Action: Restore from backup before corruption
  Command: List backups, choose good point, restore

SCENARIO: Malware/Ransomware
  Recovery Time: 30 minutes
  Action: Restore from external USB backup
  Location: External USB drive backup location
