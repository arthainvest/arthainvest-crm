3. Name it: ArthaInvestCRM_Setup.zip
4. This ZIP file is what you send to your team

STEP 2: SEND TO TEAM (5 minutes)
────────────────────────────────

Send the ZIP file via:
   ☐ Email to team members
   ☐ Shared network folder
   ☐ Cloud storage (OneDrive, Google Drive)
   ☐ Slack/Teams channel

Include in message:
   - Download/access link
   - Installation instructions (from QUICKSTART.txt)
   - Their username
   - Default password: 123
   - Your contact info for support

STEP 3: TEAM INSTALLS (15 minutes per person)
──────────────────────────────────────────────

Each team member:
