🎯Getting Started

Access Your CRM

  1. Open Google Sheets
  2. Search for: "ArthaInvest CRM ADVANCED"
  3. Bookmark it (you'll use it daily)
  4. Share the link with team members

What You'll See

  • 15 sheets at the bottom (tabs)
  • Menus at top right: Notifications | Workflows | Lead Scoring | Email Sequences | Communication Hub
  • Color-coded sheets for easy navigation

Your Role

✅ What You Do
  • Add data to Leads, Clients, Deals, Tasks
  • Monitor dashboards and notifications
  • Act on tasks and follow-ups
  • Track all communications
🤖 What System Does
  • Auto-calculates lead scores

📅Daily Workflow

Morning (5 minutes)

1. Open Dashboard Sheet

✓ Check KPIs: Total clients, active prospects, open deals
✓ Review pending tasks
✓ Check upcoming renewals

2. Check Notification Log

✓ See what happened overnight
✓ Alerts about hot leads, renewals, dormant clients

3. Review Lead Scoring

✓ Filter by "HOT" (score 80-100)
✓ These need immediate calls

During Day (ongoing)

Add New Leads

Go to Leads sheet
Add: Name, Phone, Email, Company, Source, Product Interest
✓ System auto-calculates score
✓ Auto-creates notification (if high priority)

Log Communications

Go to Communications sheet
Record: Who, when, channel (Email/WhatsApp/Call), outcome
✓ Auto-updates timeline

Track Deals

Go to Deals sheet
Update stage as you move forward
✓ System auto-sends notifications

Manage Tasks

Go to Tasks sheet
Add: Description, priority, due date, related lead
✓ System sends reminders

End of Day (5 minutes)

1. Update Last Contact

Mark in Leads/Clients: Today's date in "Last Contact" column
✓ System updates Communication Hub

2. Check Tomorrow's Tasks

Filter Tasks sheet by tomorrow's date
✓ Prepare for next day

🔥Key Features

Feature 1: Auto Lead Scoring

✅ What it does

Every lead gets a score (0-100) automatically based on:

  • Engagement (email, calls, meetings)
  • Company fit & size
  • Budget & timeline
  • Recent activity

✅ How to use

Add a lead → System scores it → Check tier in Lead Tier column

✅ Action

Focus on HOT leads first (80-100)

Feature 2: WhatsApp Notifications

✅ What you'll get

Instant WhatsApp alerts for:

  • 🔔 New lead assigned
  • 🔔 Lead score changed to HOT
  • 🔔 Deal created
  • 🔔 Renewal due (7 days before)
  • 🔔 Commission earned
  • 🔔 Client dormant (30+ days)

✅ Action

Check Notification Log sheet to see all alerts

Feature 3: Automatic Task Creation

✅ What system creates

  • New lead assigned → Welcome task

Complete tasks as they appear in Tasks sheet

Feature 4: Email Sequences

24/7 automated email outreach - no manual work needed

✅Common Tasks - Step by Step

Task 1: Add a New Lead

Steps:
  1. Open Leads sheet
  2. Add new row with basic info:
    • Name: "Rajesh Patel"
    • Phone: "98765-43210"
    • Email: "rajesh@company.com"
    • Source: "LinkedIn"
    • Product Interest: "Term Insurance"
    • Budget: "50,00,000"
    • Timeline: "2" months
✓ System automatically: Scores lead, assigns tier, sends notification

Task 2: Log a Phone Call

Steps:
  1. Open Communications sheet
  2. Add new row:
    • Date: Today
    • Contact: "Rajesh Patel"
    • Channel: "Phone Call"
    • Subject: "Discussed budget & timeline"
    • Duration: "15" minutes
    • Outcome: "Very interested"
✓ System updates: Communication Hub, last contact date, lead score

Task 3: Update Deal Stage

Steps:
  1. Open Deals sheet
  2. Find the deal
  3. Change "Stage" column from "Proposal" to "Negotiation"
✓ System creates: Notification, updates pipeline value
💡 Tip: When you move to "Closed Won", system auto-creates renewal task

Task 4: Create Follow-up Task

Steps:
  1. Open Tasks sheet
  2. Add new row:
    • Description: "Call Rajesh Patel to discuss quotation"
    • Related To: "Rajesh Patel"
    • Priority: "High"
    • Due Date: "2026-08-25"
    • Status: "Pending"
✓ System: Sends reminder on due date, links to lead profile

Task 5: Check Your Priorities

Steps:
  1. Open Leads sheet
  2. Click filter icon on "Lead Tier" column
  3. Select "HOT" only
  4. Now see only high priority leads to call today
✓ Focus on: Leads with score > 80 first

Task 6: Monitor Client Renewals

Steps:
  1. Open Clients sheet
  2. Look at "Renewal Date" column
  3. Any date in next 7 days = URGENT
✓ System alerts: Notification 7 days before, creates task

Task 7: Track Commission

Steps:
  1. Open Commissions sheet
  2. See all commissions earned (auto-logged)
  3. Check status: Earned / Pending / Paid
✓ Know exactly how much you've earned

💡Tips & Tricks

💡 Tip 1: Use Filters - Click column header → Filter icon → Filter by Tier (HOT), Status (Pending), Priority (High)
💡 Tip 2: Use Search (Ctrl+F) - Search for lead name across all sheets - Find all interactions with one person
💡 Tip 3: Sort by Last Contact - Oldest contacts first = who needs re-engagement
💡 Tip 4: Check Dashboards Daily - Dashboard sheet (KPIs) + Communication Hub (health) + Notification Log (events)
💡 Tip 5: Respect Preferences - Check Communication Preferences sheet - Some prefer WhatsApp, some email
💡 Tip 6: Batch Similar Tasks - Group calls by location + Group emails by sequence = More efficient
💡 Tip 7: Update "Last Contact" Column - System uses this for scoring & alerts - Keep dormant detection accurate
💡 Tip 8: Set Realistic Follow-ups - Don't create too many tasks - Focus on HIGH priority only
💡 Tip 9: Review Performance Weekly - Open Sequence Logs - Check open rates (target 25%+) & click rates (target 5%+)
💡 Tip 10: Trust the Automation - Workflows run 24/7 + Sequences send automatically + Scores update automatically
