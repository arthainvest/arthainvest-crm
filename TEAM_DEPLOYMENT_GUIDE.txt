  STEP 7: CREATE ADDITIONAL USER ACCOUNTS
================================================================================

When you need to add more team members:

METHOD 1: Edit the database directly (requires admin knowledge)
   1. Close the CRM
   2. Download SQLite Browser: https://sqlitebrowser.org/
   3. Open arthainvest_crm.db
   4. Go to "Execute SQL" tab
   5. Run:
      INSERT INTO users (username, password, role, email)
      VALUES ('newuser', '[hashed_password]', 'Employee', 'email@company.com');
   6. Restart CRM

================================================================================
  FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Can my team use the CRM on their home computers?
A: Yes! Each person installs on their own computer.

Q: Can multiple people use the same account?
A: Not recommended. Each person should have their own account.

Q: What if someone forgets their password?
A: They can reset it using the "Change Password" feature if they know the old one.
   Otherwise, you'll need to update their password in the database.

Q: Can we use this on Mac/Linux?
A: Yes, but the installer is Windows. Mac/Linux users can run:
   python arthainvest_crm_app.py directly.

Q: What if the database gets corrupted?
A: Delete arthainvest_crm.db and restart the app. A fresh database will be created.

Q: Can we export data?
A: Yes, the database is SQLite. Use SQLite Browser to export to CSV.

Q: How do we backup data?
A: Copy the arthainvest_crm.db file to a safe location.

Q: Is the CRM secure?
A: Yes:
   - Passwords are hashed with SHA-256
   - Local database only (no cloud)
   - Role-based access control
   - All data stays on user's computer
