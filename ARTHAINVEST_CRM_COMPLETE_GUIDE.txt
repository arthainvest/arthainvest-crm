1. SYSTEM OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

ArthaInvest CRM is an enterprise-grade financial services management platform
designed for field teams, team leaders, marketing teams, and administrators.

Core Components:
  ✓ Backend API (Node.js/Express)
  ✓ SQLite Database
  ✓ Admin Dashboard (Professional UI)
  ✓ Team Leader Dashboard
  ✓ Marketing Dashboard
  ✓ Field Team Mobile App
  ✓ Integrated Communication Platform
  ✓ AI Automation Engine
  ✓ Real-time Analytics

Technologies:
  • Backend: Node.js, Express.js
  • Database: SQLite3
  • Authentication: JWT + bcrypt
  • Frontend: HTML5, CSS3, JavaScript
  • API: RESTful JSON
  • Security: Rate limiting, CORS, encryption

10. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

CANNOT LOGIN:
  • Check username and password are correct
  • Try demo account first to verify system works
  • Clear browser cache and cookies
  • Try a different browser
  • Ensure backend server is running

BACKEND SERVER NOT STARTING:
  • Check if Node.js is installed: node --version
  • Check if npm packages are installed
  • Delete node_modules folder and run: npm install
  • Check if port 3000 is available (not used by another app)
  • Kill any existing Node processes

DATABASE ISSUES:
  • If database file is corrupted, delete arthainvest.db
  • System will recreate it on next startup
  • All data will be reset

VOICE RECORDING NOT WORKING:
  • Check microphone permissions in browser
  • Try a different browser (Chrome recommended)
  • Check microphone is connected and working
  • Ensure HTTPS is not required for local testing

DOCUMENTS NOT UPLOADING:
  • Check file size is under 50MB
  • Check file format is supported (images/PDF)
  • Verify client is selected
  • Check file permissions

EMAILS/WHATSAPP NOT SENDING:
  • Verify API credentials are configured
  • Check phone number format (country code required)
  • Verify WhatsApp/email account is active
  • Check message length limitations

PERFORMANCE SLOW:
  • Close browser tabs to free memory
  • Clear browser cache
  • Check database file size
  • Restart backend server
