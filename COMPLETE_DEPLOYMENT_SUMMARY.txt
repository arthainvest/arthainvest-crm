MARKETING MATERIALS FEATURE

What you can do:
  ✅ Create marketing materials (brochures, guides, offers, etc.)
  ✅ Store materials with names, types, descriptions, links
  ✅ Share to selected clients via WhatsApp (one click per client)
  ✅ Share to selected clients via Email (one click per client)
  ✅ Material types: Brochure, Guide, White Paper, Product Info, etc.
  ✅ Delete materials
  ✅ Track when materials were created and by whom

How to use:
  1. Login to CRM
  2. Click "📢 Marketing" in sidebar
  3. Click "+ Add Marketing Material"
  4. Fill in: Name, Type, Description, Link (optional)
  5. Click "Save Material"
  6. To share: Click "📱 WhatsApp" or "✉️ Email"
  7. Select clients to share with
  8. Material links open on their devices

Example use cases:
  • Share investment guides to new leads
  • Send special offers via WhatsApp
  • Email monthly newsletter to all clients
  • Promote new products
  • Share policy information

Requirements for sharing:
  • WhatsApp: Client needs phone number with country code (+919876543210)
  • Email: Client needs valid email address
  • If missing, system warns you

📞 SUPPORT & TROUBLESHOOTING

Common Issues

Issue: Installer won't run
  → Right-click → Run as Administrator
  → Check antivirus isn't blocking
  → Restart computer and try again
  → Reinstall Windows if absolutely stuck

Issue: Login fails
  → Check username: artha (lowercase)
  → Check password: artha123 (exact match)
  → Clear browser cache
  → Check CAPS LOCK is off
  → Contact manager for credential reset

Issue: Documents won't upload
  → Check file size (under 10MB)
  → Try shorter filename
  → Refresh page (F5)
  → Check internet connection
  → Try different document type

Issue: Marketing materials not saving
  → Check all fields filled (Name required)
  → Refresh page
  → Restart app
  → Check browser compatibility

Issue: WhatsApp sharing not working
  → Make sure client has phone number saved
  → Phone must have +country code (+91 for India)
  → Install WhatsApp first
  → Try email instead if WhatsApp fails

Issue: Data not syncing between laptops
  → Export CSV from desktop
  → Email CSV to mobile/other laptop
  → Import CSV there
  → Sync complete!
