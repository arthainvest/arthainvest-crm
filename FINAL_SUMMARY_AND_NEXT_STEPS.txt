📞 SUPPORT & TROUBLESHOOTING

COMMON ISSUES:

1. Installer won't run
   → Right-click → Run as Administrator
   → Check antivirus isn't blocking

2. Login fails
   → Username: artha (all lowercase)
   → Password: artha123 (exact match)
   → Check CAPS LOCK is off

3. Can't see "Manage Users"
   → You're logged in as Employee, not Admin
   → Login as: artha / artha123
   → Then you'll see ADMIN section

4. Documents won't upload
   → File size must be under 10MB
   → Check internet connection
   → Try PNG/JPG/PDF files

5. WhatsApp sharing not working
   → Client must have phone number saved
   → Phone format: +919876543210 (with +country code)
   → Install WhatsApp first (or use email)
