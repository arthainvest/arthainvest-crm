     - Document Type (dropdown)
   Document Types Available:
     • PAN Card
     • Aadhaar
     • Insurance Policy
     • Bank Statement
     • Agreement
     • Invoice
     • Other

✅ JavaScript Functions
   Location: app.js

   1. renderDocuments()
      - Displays clients with document folders
      - Shows document count per client
      - Handles empty state
      - Role-based filtering

   2. openDocumentUpload(clientId)
      - Opens upload modal
      - Sets client ID context
      - Prepares form for input

   3. closeDocumentModal()
      - Closes modal
      - Clears form fields
      - Resets state

   4. uploadDocument()
      - Validates input
      - Creates document metadata
      - Saves to crmData
      - Triggers renderDocuments()

   5. deleteDocument(clientId, docId)
      - Confirms deletion
      - Removes from storage
      - Updates display

✅ Data Structure
   Location: crmData.documents (line 9)
   Format: {clientId: [{id, name, type, uploadedAt, uploadedBy}]}
   Example:
   {
     "lead_001": [
       {
         id: "doc_1691234567890",
         name: "PAN Card",
         type: "PAN",
         uploadedAt: "2026-08-07T16:45:00.000Z",
         uploadedBy: "ArthaInvest Admin"
       }
     ]
   }

✅ Navigation Wiring
   Location: app.js, navigateTo() function
   Added: 'documents' case
   Calls: renderDocuments()
   Updates: Page title to "Client Documents"

✅ Data Persistence
   Mechanism: localStorage (browser) + AppData (desktop)
   Persistence: Automatic on every save
   Survival: App restart, browser close
   Backup: CSV export available
